# 🎓 Student Registration Application using Amazon EC2 & Amazon RDS

## 📌 Project Overview

This project demonstrates the deployment of a **Student Registration Application** using **Amazon EC2** as the web/application server and **Amazon RDS MySQL** as the database server.

The application allows users to enter student details through a web form. The submitted student information is securely stored in the RDS MySQL database and can be retrieved and displayed from the application.

---

## 🏗️ Architecture

```text
                Internet
                    |
                    |
              Public IP / DNS
                    |
                    ▼
              Amazon EC2
          Web/Application Server
                    |
                    |
          Secure Database Connection
                    |
                    ▼
             Amazon RDS
              MySQL Database
                    |
                    ▼
            Student Records
```

# 🚀 Project Setup

## 1. Launch EC2 Instance

Create an EC2 instance with:

* Operating System: Amazon Linux / Ubuntu
* Instance Type: Free Tier eligible instance
* Security Group:

  * SSH – Port `22`
  * HTTP – Port `80`
  * HTTPS – Port `443` (optional)

Example:

```text
EC2 Instance
Public IP: <EC2-PUBLIC-IP>
```

---

## 2. Connect to EC2

Connect to the EC2 instance using SSH.

```bash
ssh -i "your-key.pem" ec2-user@<EC2-PUBLIC-IP>
```

For Ubuntu:

```bash
ssh -i "your-key.pem" ubuntu@<EC2-PUBLIC-IP>
```

---

## 3. Install Required Packages

For Amazon Linux:

```bash
sudo dnf update -y
sudo dnf install python3 -y
sudo dnf install git -y
```

Install Flask and MySQL connector:

```bash
pip3 install flask mysql-connector-python
```

---

# 🗄️ 4. Create Amazon RDS MySQL Database

Create an RDS MySQL database with:

```text
Engine       : MySQL
Database     : studentdb
Username     : admin
Password     : ********
Port         : 3306
```

Make sure the RDS Security Group allows MySQL traffic:

```text
Type       : MySQL/Aurora
Port       : 3306
Source     : EC2 Security Group
```

> For better security, allow port `3306` from the EC2 Security Group instead of allowing `0.0.0.0/0`.

---

# 🔐 5. Configure Database Connection

Get the RDS endpoint from:

**AWS Console → RDS → Databases → Your Database → Connectivity & security**

Example:

```text
student-database.xxxxxxxxx.us-east-2.rds.amazonaws.com
```

Application database configuration:

```python
DB_HOST = "student-database.xxxxxxxxx.us-east-2.rds.amazonaws.com"
DB_PORT = 3306
DB_NAME = "studentdb"
DB_USER = "admin"
DB_PASSWORD = "your-password"
```

# 🗃️ 6. Create Database and Table

Connect to the RDS MySQL database:

```bash
mysql -h <RDS-ENDPOINT> -P 3306 -u admin -p
```

Create the database:

```sql
CREATE DATABASE studentdb;
```

Select the database:

```sql
USE studentdb;
```

Create the student table:

```sql
CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL,
    course VARCHAR(100),
    phone VARCHAR(15)
);
```

Check the table:

```sql
SHOW TABLES;
```

# 💻 7. Student Registration Application

Example Flask application:

```python
from flask import Flask, request, render_template
import mysql.connector

app = Flask(__name__)

db = mysql.connector.connect(
    host="RDS-ENDPOINT",
    user="admin",
    password="YOUR-PASSWORD",
    database="studentdb",
    port=3306
)

@app.route("/")
def home():
    return render_template("index.html")

@app.route("/register", methods=["POST"])
def register():

    name = request.form["name"]
    email = request.form["email"]
    course = request.form["course"]
    phone = request.form["phone"]

    cursor = db.cursor()

    query = """
    INSERT INTO students (name, email, course, phone)
    VALUES (%s, %s, %s, %s)
    """

    cursor.execute(query, (name, email, course, phone))
    db.commit()

    cursor.close()

    return "Student registered successfully!"

@app.route("/students")
def students():

    cursor = db.cursor(dictionary=True)

    cursor.execute("SELECT * FROM students")

    data = cursor.fetchall()

    cursor.close()

    return str(data)

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=80)
```
